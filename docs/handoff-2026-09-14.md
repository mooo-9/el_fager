## How Mo likes to work

- **One step at a time.** Propose the step, build it, show proof, then ask
  before moving on. Never bundle several ideas into one change.
- **Tests first**, confirmed failing before the fix; full suite before commit.
- **Verify for real, not just in tests**: render the Cockpit at Mo's screen
  size (1536×816 logical, 125% scaling), run against the live model, real
  Groq/Windows audio, real WhatsApp/Gmail/Comet where it's cheap, and check

  a second launch exits on the instance lock), then start
  `pythonw.exe "C:\claude proj\el_fager\main.py"` from the repo root, and
  confirm it is still running ~25 s later.
- **Real sends only with Mo's OK, and only to Mo.** Tests used
  mohabmohamed154@gmail.com and his own "Mo (You)" WhatsApp chat.

## Shipped 2026-09-15

### Email and confirming ("yes, send it")
- **The confirm loop is fixed.** History keeps only the final text, so the
  model never knew a draft was staged and redrafted on every "yes". Now:
  - Each turn's prompt names what's staged.
  - `confirm_staged_action` and `cancel_staged_action` are always offered.
- **Guards** (`core/brain.py`):
  - A confirm only runs if the draft was already staged when the turn began,
    so the model can't stage and send in one turn.
  - Background turns never see or confirm Mo's draft.
  - A refused confirm is a tool error saying "NOT SENT", so the model stops
    claiming it sent.
  - Any turn while something is staged goes to the full model, because Haiku
    once said "Cancelled" without cancelling.
- **The Cockpit's Enter** sends off the GUI thread, and only once.
- **Gmail** HTTP calls time out after 30 s, and the OAuth page after 120 s.
- Verified: a real Gmail send and a threaded reply to Mo's address, through
  typed pipeline turns.

### WhatsApp to any saved chat (`tools/whatsapp_desktop.py`)
- **Driver:** WhatsApp Desktop (a WebView2 app) through Windows UI
  Automation, using `comtypes` (added to `requirements.txt`).
- **Drafting:**
  - Fills WhatsApp's search box without taking focus. A minimized window is
    restored behind all others, then minimized again.
  - Reads chat names and crops each chat's profile photo from a
    `PrintWindow` capture.
- **Sending:**
  - Opens the chat with one click and checks the message box is named
    "Type a message to <chat>".
  - Before the paste and before Enter, checks that WhatsApp is in front and
    the box has keyboard focus.
  - Afterwards confirms the box emptied, and restores the clipboard, the
    previous foreground window and the minimized state.
- **Picking the chat** (`tools/whatsapp_tool.py`):
  - The name Mo says is a chat's full name: that chat wins.
  - Otherwise, one chat where every word starts a name word: that chat.
  - Several matches: El Fager lists them and asks. The near misses aren't
    mentioned otherwise, because that made the model ask while the card
    already showed the draft.
  - No match: falls back to `data/contacts.json` numbers.
- **The draft card shows the photo** beside the message, on both the Cockpit
  and the overlay (`round_photo` in `ui/overlay.py`). The photo travels as
  `StagedAction.photo` and is kept in memory only.
- **Chats saved in Arabic:**
  - `prepare_whatsapp_message` requires `contact_name_arabic`. For names that
    are also words the model gives both spellings, sound-alike and
    translation ("كينجز | الملوك").
  - The Arabic spellings are searched only when the English one finds
    nothing.
  - Matching folds أ/إ/ا, ة/ه and ى/ي, strips vowel marks, allows a joined
    "و" or "ال", and treats دكتور/"د." as "د".
- **Verified:**
  - Real sends to Mo's own chat.
  - Live-model matrices on his real contacts: 18/18, plus Arabic chats
    (زوزو معندوش زوزو, د محمد طه عظام, الملوك only).

## Gotchas learned

- **Tests must never touch Mo's real data or apps.**
  - Autouse fixtures in `tests/conftest.py` redirect the Trust Ledger,
    `voice_learned` and `voice_liked`, and block real WhatsApp
    (`_no_real_whatsapp`) and real Comet/browser launches (`_no_real_comet`).
  - Cockpit tests redirect `settings.json`; ducking is off in
    `EL_FAGER_TEST_MODE`.
  - Ad-hoc live scripts must divert the same things. A WhatsApp matrix once
    wrote fake contacts into the real `data/voice_learned.json`, and an
    unstubbed YouTube check opened a real video.
- **The slimmed tool list drops parameter descriptions** (`_slim_tools`
  keeps only type/enum/items). Put instructions in the tool's own
  description, and make essential fields required: the model ignored an
  optional, undescribed `contact_name_arabic`.
- **The model doesn't know the date** unless the prompt says so; it's in
  `_build_system`'s dynamic block now.
- **WhatsApp Desktop via UI Automation**
  - Searching from the window root loops through repeated WebView host panes
    (an absent element took seconds); scope lookups to the `RootWebArea`
    document.
  - comtypes returns NULL pointers, not `None` — test truthiness.
  - The search box loses its name once it has text; the composer ignores
    `SetValue` (paste instead).
  - Rows ignore `Select()`/`DoDefaultAction()` (a real click is needed).
  - `SetFocus()` on the composer moves the foreground to the WebView window;
    use `CurrentHasKeyboardFocus`.
  - A minimized window stops rendering (stale results); restore it behind.
  - Results first show the unfiltered chat list; wait for the real matches.
  - A stale "No chats, contacts or messages found" text poisons the next
    search.
- **DPI:** at 125% scaling a DPI-unaware thread gets scaled window
  coordinates while UIA reports physical ones. Set per-monitor awareness
  before capturing or clicking.
- **Comet:** `comet.exe <url>` opens in the last-active profile unless
  `--profile-directory` is given; a Comet started without the port can't
  gain one without restarting.
- **Qt in tests:** free QPixmap/QImage on the main thread (a pixmap freed by
  the collector from a worker thread crashed the suite); don't import Qt
  modules from root-level tests (`tests/` vs `tests/ui/`); a wrapped QLabel
  in an AlignTop layout gets its unwrapped height and clips. The offscreen
  platform has no emoji font — check emoji with the Windows platform.
- **`mapTo()` only works toward an ancestor** — map sibling widgets through
  the window.
- **Spotify:** adding a scope to playback's login would reopen the browser on
  the next "play"; the library login is separate for that reason.
- **Shell traps**
  - `grep … && python …` skips the script when grep finds nothing.
  - Heredocs containing Arabic, backslashes or quotes broke the Bash tool
    several times; write scripts to a file instead.
  - Python text-mode rewrites of CRLF files are fine (git's autocrlf
    normalises them).
