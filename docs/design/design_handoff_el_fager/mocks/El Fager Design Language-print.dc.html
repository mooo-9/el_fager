V5 — SYSTEM DEPTH · PROACTIVE BEHAVIOR + EDGE STATES (SETTINGS & ONBOARDING SHIP AS PROTOTYPES)
V5 — PROACTIVE & EDGE STATES
When it speaks first, and when it can't
PROACTIVE — THE KNOCK RULE
El Fager never barges into the room. Every proactive moment follows knock → wait → enter: the tray sun brightens + one soft chime (the knock), a one-line banner slides from the tray naming what it has ("Morning brief ready — 2 things need you"), and it speaks ONLY if Mo clicks, says "go ahead", or has marked that routine speak-first in Settings. Unanswered knocks fade after 30s into a receipt in the Command Center — never a badge, never a nag.
Mode choreography. Focus: the cockpit dims to ambient, knocks are held silently and delivered as a digest on exit. Gym: knock on geofence arrival, then voice-only exchanges — big text, no cards except set-logging receipts. Evening shutdown: one knock at the set hour, tomorrow-preview data moment, then the orb visibly "goes to sleep" (600ms decay to ash).
EDGE STATES — THE ORB NEVER LIES
Offline — orb desaturates to ash, rings stop, label OFFLINE · القطع. Outbound actions queue as amber-dashed cards: "will send when back".
Mic busy / denied — waveform bars replaced by a static amber strike-through bar; typing path auto-opens. Never pretend to listen.
Updating — orb pulses slow cyan at 50%, tick ring becomes a progress arc; voice stays available for read-only asks.
Low battery (laptop) — ambient kicks in at 15s, particle count halves, canvas drops to 30fps. Cinema yields to endurance silently.
SHIPPED AS PROTOTYPES
Settings — five sections (Voice, Routines, Skills, Memory, System); every toggle live; memory facts individually forgettable; the no-off-switch staging rule stated where permissions are granted.

Onboarding — four steps, the orb present from frame one: name → voice calibration (bilingual line) → skill permissions → wake-word test. It ends with the assistant speaking, not a dashboard tour.

V3 — VOICE FIRST
Exchanges, not conversations
Critique of v1–v2: the overlay still looked like a chat app — bubbles, a thread, a text box. But Mo talks to El Fager; a scrollback is a keyboard-era artifact. V3 retires the conversation entirely. The overlay holds one live exchange at a time — what it heard, what it's doing, what it answered — then the exchange condenses into a one-line receipt. Memory lives in the assistant, not in a scrollback. Speech is the primary output; everything on screen is captions and receipts for it.

One soul: cold night, warm light
The rule that resolves everything: surfaces are always cold, light is always warm. Grounds are blue-black — real night, not neutral gray. Anything alive — the assistant's voice, actions, focus, selection — is warm. That tension is dawn, and it is the identity.

02 — THE FIVE LIGHTS
State is the interface
Voice-first means the user is often not looking at a screen — they're glancing. Each state gets a unique hue + motion signature, so it reads at 4px in the overlay and at 400px in the HUD. The hues walk the dawn arc: ash night → ember horizon → twilight sky → risen light.
idle · ساكن
#7E8AA3 — ASH
Breath: scale 1→1.10, opacity .45→.85, 3600ms sine loop. The only state with no edge — it's soft, defocused, part of the dark.
listening · سامعك
#F09950 — EMBER
The brand moment: mic open = dawn. Form rides mic RMS at 60fps, smoothed 120ms. Glow ON. Silence > 2s → bars settle to a still ember line.
thinking · بفكّر
#A48BF5 — TWILIGHT
Three orbiters, 1.4s/rev, core shimmer. Tool calls append a mono caption ("reading gmail…"). The only violet in the system — unmissable.
speaking · بتكلم
#FFD9A3 — RISEN GOLD
Light leaves the source: rings emitted on TTS cadence (~420ms nominal, synced to audio envelope). Listening reacts to you; speaking radiates outward.
error · في مشكلة

Two 90ms flashes, then steady at 75% — announce once, don't nag. Auto-returns to idle after 4s; the failure text stays in the log.

THE SUMMON — SACRED PATH
Ctrl+Space → overlay visible in one frame (window pre-created, hidden, warm). Then a single 140ms entrance: opacity 0→1, translateY 6px→0, scale .985→1, swift-out. State snaps straight to listening — the mic is already open before the animation ends.
Dismiss: 120ms, opacity→0, scale→.99, exit curve. No bounce, no spring, ever — springs read playful; El Fager is precise.
BUDGET: 0 allocations, 0 layout passes, 0 network on the summon path. If a feature costs summon latency, the feature loses.
LAWS OF MOTION
1 · One thing moves at a time. Streams of text stream; nothing else animates while they do.
2 · Organic loops pause when the window is hidden — zero idle CPU in the tray.
3 · Amplitude-reactive motion smooths input over 120ms; raw mic data looks like panic.
4 · Text never fades in word-by-word — it streams in place, monospace caret at the head.
5 · Every animation is interruptible; new state wins instantly.

11 — BUILDABILITY + RATIONALE
Where the pixels live, and why
CHEAP — QSS NATIVE
Every color, border, radius, padding token · text styles · buttons, chips, inputs, cards, list rows · QScrollBar restyle · hover/pressed via QSS pseudo-states.

The entire overlay and 90% of the Command Center are this tier. Ship fonts bundled (Space Grotesk, Alexandria, Spline Sans Mono — all OFL), never fetch.
MODERATE — QPAINTER
State dot + amplitude bars (one 60fps QTimer, repaint a ≤32px rect — negligible) · calorie ring, macro bars, sparklines (static paints, animate only on first show) · the 140ms summon fade (QPropertyAnimation on windowOpacity).

Rule: QPainter may animate small regions, never full windows.
EXPENSIVE — QWEBENGINE ONLY
The HUD orb (canvas, particles, glow) · rich news reader · any future charts. Lazy-loaded, killed on hide, hard-capped to one live instance.

Nothing web-rendered may ever sit on the Ctrl+Space path. The overlay window is pre-created at boot and only ever shown/hidden.
THE BIG CALLS
Ember over cyan — cyan is genre wallpaper; warmth is what makes a personal assistant feel personal. The sci-fi feeling survives in the cold surfaces and mono data type, so we keep the cinema and lose the cliché.

Assistant gets no bubble — a boxed assistant is a chat app. Words on the night with an ember rule make it the environment, which is what an operating layer is.

Violet thinking — the one cold-adjacent state hue. Deliberate: thinking is the assistant off in its own sky; the warm hues are reserved for the moments it touches Mo (hearing him, answering him).

Glow = armed — glow is a promise, not a garnish. If it glows, either a mic is open or an action is staged. This single rule is most of the product's trustworthiness.
LIGHT THEME · FLUENT · TRADEOFFS
No light theme. The identity is light against dark — invert it and the five lights lose their legibility and the glow grammar dies. The honest daytime concession is a brightness axis, not a theme: at high ambient light, raise text contrast and surface values one step (surface.0→1). Cheap in QSS, identity intact.

Alongside Windows, not of it. No Mica, no acrylic, no Fluent corners. El Fager is a place you summon, not a window you manage — visual sovereignty is the point. Concessions: Segoe-free but DPI-aware, snap-layout friendly, honors the OS reduced-motion flag (organic loops drop to slow opacity breathing).

Tradeoff owned: ember + violet + gold is a warmer, softer face than a classic HUD — it will read "calm" before "powerful." Chosen deliberately: Mo lives with this thing 50× a day; awe wears off, calm doesn't.
